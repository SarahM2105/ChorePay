# ChorePay Product Vision

## Product Summary

ChorePay is a gamified mobile application that turns household chores into pixel-style quests.

Parents can create and assign chores, review completed tasks and reward children with experience points, game coins or real-life rewards such as money, vouchers and activities.

Children can view their assigned quests, submit completed chores, earn rewards, level up and customise their game experience.

## Problem

Traditional chore charts can feel repetitive and unmotivating for children. Parents may also find it difficult to consistently track completed chores and manage rewards.

ChorePay aims to make household responsibilities more engaging while giving parents a structured way to manage chores and rewards.

## Target Users

- Parents or guardians who manage household chores
- Children who complete chores and earn rewards

## Main Goals

- Make household chores more engaging
- Encourage responsibility and consistency
- Allow parents to approve completed chores
- Store users, chores and rewards securely in a PostgreSQL database
- Provide live updates between parent and child accounts
- Create a fun pixel-art mobile experience
- Make the application accessible from different devices

## Initial Technology Stack

- React Native with Expo and TypeScript
- Java with Spring Boot
- PostgreSQL
- Spring Data JPA
- Spring Security and JWT
- WebSockets for live updates
- GitHub Projects for Agile and Kanban planning

## Development Approach

The project will follow Agile principles and use a Kanban board to track work through the following stages:

- Backlog
- Ready
- In Progress
- Review
- Testing
- Done
