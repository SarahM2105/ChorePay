# ChorePay Software Requirements Specification

## 1. Introduction

### Purpose

ChorePay is a gamified mobile application that helps families manage chores and rewards.

Parents create and assign chores, approve completed work and manage rewards.

Children complete chores, earn coins and XP, level up and redeem rewards through a reward shop.
